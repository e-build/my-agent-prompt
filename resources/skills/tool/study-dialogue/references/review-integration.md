# study 복습과 연결

## 구조

- 복습은 **챕터 단위**다. 일정은 study 루트의 `review/schedule.json` 한 파일에 모든 프로젝트의 챕터가 있다. 간격은 +1 / +3 / +7 / +14일이고 마지막 회차 뒤 끝난다.
- 개념 교재는 챕터의 `concepts/NN-<slug>.md`다. 복습 질문의 재료는 각 개념 파일의 "스스로 확인"과 "흔한 오해", 지난 시험의 약점 문항이다.
- 질문·응답 기록은 프로젝트 `.study/cards/<챕터 slug>.jsonl`에 추가만 된다(append-only). 이 파일과 일정 파일은 직접 편집하지 않는다.

## Pi study 도구를 쓸 수 있을 때

대화를 정식 복습 회차로 남기려면 study 도구의 흐름을 그대로 따른다.

1. `study_review_next`로 오늘 기한인 챕터를 확인한다. 기한 전인 챕터는 회차로 기록하지 않는다(미래 회차를 당기지 않음).
2. 회상 질문을 `study_ask`(purpose=review, chapterSlug)로 만든다. 채점 기준이 먼저 저장되므로, 대화 중에 질문을 즉석으로 바꿨다면 바뀐 질문으로 새 카드를 만든다.
3. 학습자의 답을 문항마다 `study_answer_record`로 기록한다. 혼자 떠올린 답은 independent, 힌트 후 답은 hinted, 설명을 듣고 보완한 답은 explained 또는 `correctionOf`. 확신도는 학습자가 말한 값 ÷ 10만 넣는다.
4. `study_review_finish`로 회차를 기록한다. 모든 문항이 independent+demonstrated일 때만 다음 간격으로 간다. 날짜는 도구가 계산한다.

자유 대화(질문 카드 없이 나눈 대화)는 회차로 바꾸지 않는다. 회차로 남기고 싶다면 위 2번부터 다시 질문한다. 이미 설명을 들은 개념은 독립 회상으로 세지 않는다.

## 도구를 쓸 수 없는 환경

- `review/schedule.json`, `.study/cards/`, `.study/state.json`을 직접 편집하지 않는다.
- 대화 메모만 남기고, 정식 회차 기록은 Pi에서 `/study-review`로 해야 한다고 알린다.

## 대화 메모

챕터 폴더의 `dialogue/YYYY-MM-DD-NN.md`에 다음 대화의 질문을 고르는 데 필요한 내용만 남긴다. NN은 같은 날 기존 파일을 확인해 충돌 없이 정한다. 날짜는 study 루트 `workspace.json`의 timezone 기준이다.

- 날짜, 챕터, 다룬 개념, 정식 회차로 기록했는지(카드 ID) 여부
- 스스로 설명한 개념이나 관계
- 도움받은 부분과 이후 이해 확인 여부
- 다음에 확인할 구체적인 관계나 질문. 단순히 생략한 내용은 이해 부족으로 적지 않는다

질문·답변 전문, 발언별 판정은 메모에 넣지 않는다(정식 회차라면 카드 기록에 이미 있다). 기존 메모는 덮어쓰지 않고 새 파일을 만든다.

## 판정 원칙

- 판정은 이번 응답의 평가일 뿐 장기 기억 인증이 아니다.
- 본 학습에서 다루지 않은 내용은 학습 공백으로 따로 적고 오답으로 기록하지 않는다.
- 같은 날 여러 대화를 밀린 회차 여러 개로 기록하지 않는다.
- 파일 저장과 회차 기록 중 어디까지 성공했는지 구분해 보고한다. 실패한 저장을 성공으로 말하지 않는다. Git 커밋·푸시는 하지 않는다.
