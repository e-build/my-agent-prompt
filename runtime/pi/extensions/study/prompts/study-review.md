## 진입과 일정 설정

- 현재 cwd의 study 프로젝트 탐색. `$1`은 챕터 slug 또는 숫자. 인자 없음이면 schedule.md 기준 가장 오래 기한이 지난 미완료 회차 우선. 기한 경과가 없으면 오늘 예정 우선.
- 모두 미래 일정이면 당겨서 지연 회상을 수행하지 않음. 다음 예정 안내 또는 학습자가 요청한 보충만 수행.
- 설정된 일정이 없으면 학습자에게 고정 회차의 간격·기준일·시간대 확인. 합의 전 자동 날짜 배정 금지. 특정 간격을 연구상 최적이라 주장하지 않음.
- 챕터 README는 오프라인 단권화 교재. review/README.md는 정의·정답 미노출 시작 페이지. 일정 원본은 review/schedule.md 하나.
- review/README.md와 schedule.md에서 현재 위치 확인. 질문·평가 근거는 README 개념 본문, lab 결과, 진단/시험 기록에서 에이전트가 확인하되 답변 전 모범 답안 노출 금지.
- 초기 설정에서 학습 범위의 핵심 개념 5개를 C1~C5로 등록. 시작 페이지에는 이름과 교재 위치만 공개. 개념이 더 필요하면 학습자와 범위를 합의, 회차마다 임의로 바꾸지 않음.
- `$2`의 R1 등은 해당 회차 선택. 기존 blank-recall/gap-fill/self-lecture/analogy-lock/schedule 인자는 활동 요청으로 호환하되 회차 전체를 순차 완료시키는 명령으로 해석하지 않음.
- 일정 등록만으로 review completed 처리 금지. 새 회차를 기다리는 동안 다음 챕터 본 학습 진행 가능.

## 고정 회차의 공통 원칙

- 학습 직후 오개념 교정은 최초 이해 확보. 같은 날 연속 활동을 여러 지연 복습 회차로 세지 않음.
- 매 지연 회차 같은 핵심 개념을 문서 없이 기억에서 꺼내는 경험 반복. 설명·판단·예측도 기억에서 수행하면 회상으로 인정.
- 공통 순서: 독립 응답 → 판정 → 틀린 부분만 보충 → 필요한 교정 확인 → 최초 응답과 교정 응답 분리 기록.
- 회차별 강조점은 기본 구분 / 이유·흐름 / 변형 상황·실패 / 유지 확인. 학습 활동을 회차별 독점 단계로 분리하지 않음.
- 같은 개념·일부 기준 질문의 반복 허용. 사례와 표현은 적절히 변경. 매번 완전히 새로운 문제만 강제하지 않음.
- 실제 회상한 개념 ID를 기록. 설명 하나가 여러 개념을 다루면 중복 질문하지 않음. 예측으로 범위가 빠지면 짧은 추가 질문만 제시.
- 이전 STRONG도 이후 회차에서 반복 대상. 틀린 항목만 영구적으로 복습하지 않음.
- 예정일 초과는 실패·불성실 아님. 실제 수행일과 학습자 확인에 따른 최근 교재 열람·보충 시점 기록. 밀린 회차를 같은 날 몰아쳐 완료하지 않음. 이후 예정일은 합의 없이 이동하지 않음.
- 중요한 오개념은 즉시 좁혀 보충 가능. 보충 성공을 별도의 독립 지연 회상 성공으로 계산하지 않음.

## 입력 방식

- 매 회차 시작 시 STT 또는 텍스트 방식 선택 질문. 상황·선호 확인 전 구두 설명 요구 금지. 중간 전환 가능.
- 입력 방식과 학습 활동 분리. 텍스트 회차도 설명·판단 가능하며 STT도 정의·예측 가능. 같은 개념과 정확성 기준 적용.
- STT: 질문 하나씩, 자연스러운 말로 답변. 문장 수 제한·문법·반복·말 중단으로 감점하지 않음. 인식 오류로 의심되는 단어는 의미 확인 후 판정. 앱이 실제로 측정하지 않은 음성 유창성·발화 시간 추측 금지.
- 텍스트: 짧은 문장·목록·코드 허용. 글솜씨 대신 개념·인과·판단 근거 평가.
- self-lecture는 실제 구두 설명 훈련. 초보 동료 역할의 질문을 한 번에 하나 제시. 텍스트 설명을 구두 self-lecture 완료로 기록하지 않음.
- STT 불가 시 구두 과제만 선택적으로 보류·재예약. 텍스트로 필요한 회상을 수행하면 해당 복습 회차 완료 가능. 구두 과제 대기로 다음 챕터나 전체 복습 차단 금지.
- 쉽게 설명하기는 이해 확인 도구. 정확한 전문용어 사용 자체를 감점하거나 무조건 금지하지 않음. 뜻과 관계를 본인 말로 풀 수 있는지 확인.

## 판정과 보충

- STRONG: 핵심 정확, 이번 세션 추가 보충 불필요. 이후 지연 회상 대상에서는 유지.
- WEAK: 방향은 맞으나 실제 학습한 핵심 관계 누락.
- WRONG: 오개념·미응답. STT 인식 오류 여부 확인 후 판정.
- `독립 지연 회상`, `힌트 후 응답`, `교정 직후 확인`, `학습 직후 교정` 구분. STRONG이라는 정확성 표지만으로 장기 기억 추정 금지.
- 판단 근거에 원문 위치 연결. 배운 범위 밖 조건을 새 채점 기준으로 추가하지 않음.
- WEAK/WRONG만 최소 설명 및 확인 질문 1~2개. 교재 전체 재독 금지. 정답을 듣고 반복한 답과 새로운 조건에서 판단한 답 구분.
- 비유는 필요할 때 선택. 개념마다 비유 두 개 생성 및 analogy-lock 필수 완료 금지. 사용할 경우 적용 부분과 한계 함께 확인.
- 매번 오답·학습 공백을 학습자의 불성실로 해석하지 않음.

## 본 학습 범위 가드

- 범위: 해당 README 개념 본문, diagnosis.md, lab/results.md·실제 산출물, test.md. 기존 concept.md는 레거시 근거로만 참조.
- recall gap: 배웠지만 기억 못한 부분 → 해당 회차 보충 기록.
- learning gap: 본 학습에서 안 다룬 부분 → learning-gaps.md, 본 학습으로 분리. WEAK/WRONG으로 위장 금지.
- 독립 회상·교정·사전 지식은 관찰된 응답을 근거로만 기록.

## 원본 일정 형식

학습자와 합의한 값만 schedule.md에 기록. 아래 `<...>`는 예시 자리표시자이며 날짜를 추측하지 않음.

```markdown
# 복습 일정

## 목차

- [설정](#설정)
- [반복할 핵심 개념](#반복할-핵심-개념)
- [고정 회차](#고정-회차)

## 설정

- 주기 상태: in_progress
- 기준일: <학습자 합의 YYYY-MM-DD>
- 시간대: <합의 timezone>
- 간격: <고정 간격 합의>

## 반복할 핵심 개념

| ID | 개념 이름 | 교재 위치 |
|---|---|---|
| C1 | <정의가 아닌 이름> | ../README.md#<실제-anchor> |

## 고정 회차

| 회차 | 예정일 | 상태 | 실제 수행일 | 기록 |
|---|---|---|---|---|
| R1 | <합의 날짜> | planned | - | - |
```

- 상태: planned / in_progress / completed. 문서 존재나 날짜만으로 completed 금지.
- 회차 완료 시 실제 수행일, sessions/r1.md 등 실제 기록 링크 기재. 입력 모드·개념별 판정은 회차 기록에 저장.
- 모든 예정 회차가 실제 수행된 뒤에만 `주기 상태: completed`. 의미는 예정된 복습 주기 완료이며 장기 기억 정착 인증 아님.
- 본문에 정답·개인 오답 교정 저장 금지. 시작 페이지가 개념 이름과 일정만 안전하게 읽도록 고정 표 형식 준수.

## 회차 기록과 종료

- review/sessions/r1.md 등 회차별 문서 사용. 재개·교정·재확인 기록은 append-only, 최초 응답 덮어쓰기 금지.
- 기록: 예정/실제 수행 시각·시간대, 입력 모드 및 변경, 최근 학습·힌트 여부, 질문과 개념 ID, 원 응답, 최초 판정, 교정, 교정 후 판정, 다음 회상 대상.
- 기존 blank-recall.md/gap-fill.md/self-lecture.md/analogy-lock.md는 과거 근거로 보존. 기존 회차를 새 지연 회상 성공으로 소급 계산하지 않음.
- 기존 study-pack 생성 금지. study_review_refresh가 고유 회상 구역을 legacy-recall.md에 멱등 보존하며 원본 pack 삭제 금지. 교재·오답을 시작 페이지에 복사 금지.
- 일정·회차 기록 갱신 후 study_review_refresh로 시작 페이지 갱신. 생성 실패는 경고이며 시험 통과·기록된 복습 성과 무효화 금지.
- .study/state.json의 review 상태: 미설정 not_started, 일정 설정/일부 수행 in_progress, 모든 회차 실제 완료 completed. state 갱신 시 다른 phase·active chapter 값 임의 변경 금지.
- 매 회차 종료 안내:

```text
완료: 이번 회차에서 독립 회상한 개념과 보충한 항목
다음: 다음 예정일 또는 설정 필요 / 별도 구두 과제 여부
실행: /study-review {챕터} — review/README.md
```
