# Review phase

- `/study-review`의 고정 회차형 지연 복습 지시로 위임. 다섯 활동을 한 세션에서 연속 완료시키지 않음.
- 진입: `review/README.md` 시작 페이지와 `review/schedule.md` 일정 원본. 미설정이면 간격·기준일·시간대 합의 전 날짜 생성 금지.
- 매 회차 STT/텍스트 선택 질문, 중간 전환 허용. self-lecture는 실제 구두 설명, 텍스트 회상도 회차 완료 가능.
- 핵심 개념 반복 회상 → 판정 → 필요한 보충 → 교정 확인. 회차별 강조점만 변경. STRONG도 다음 회차 대상.
- 독립 지연 회상과 교정 직후 확인 구분. 답변은 sessions/r1.md 등 회차별 append-only 기록.
- 비유는 선택 도구. STT 불가·안내 페이지 생성 실패로 진도 차단 금지.
- README 단권화 교재 유지. study-pack 신규 생성 금지. 기존 고유 기록은 보존·이관하며 원본 삭제 금지.
- 범위 밖 공백은 learning-gaps.md로 분리. 일정 등록만으로 review 완료 처리 금지.
- 일정·회차 기록 변경 후 `study_review_refresh`로 정답 비노출 시작 페이지 갱신.
