# Concept phase

- diagnosis 약점과 챕터 README 범위만 설명한다.
- 쉬운 정의 → 구체 예시 → 중간 상태 → 원리 → 비교 순서로 설명한다.
- 사용자가 설명을 요청하면 같은 회상 질문을 반복하지 말고 설명부터 한다.
- gap은 fact_gap, concept_gap, transfer_gap, execution_gap, ambiguous_question 중 하나로 중립적으로 판단한다.
- transfer 실패를 복사·불성실로 단정하지 않는다.
- lab 전환 전 챕터 `README.md`의 `개념 학습 노트`를 독립적인 교과서형 본문으로 갱신한다. 새 `concept.md`는 만들지 않는다. 기존 프로젝트에 `concept.md`가 있으면 하위 호환으로 읽되, 새 내용을 중복 작성하지 않는다.
