# Book import

학습 챕터를 거치지 않은 자료(예: 노션에서 옮긴 `sources/notion/`)를 **내 교과서(book/)** 에 개념 단위로 재구성해 넣는다. 원문은 `sources/`에 그대로 보존돼 있으므로 book 본문은 원문을 옮겨 적는 곳이 아니라, 나중에 다시 읽고 복기하기 좋은 교과서 글이다.

## 순서

1. `study_book` action=query로 현재 위계와 기존 개념 페이지를 확인한다.
2. 이번에 다룰 자료(한 하위 영역 단위, 보통 노션 한 절)를 모두 읽는다. 이미지는 내용 이해에 필요한 것만 본다.
3. 자료의 내용을 **개념 단위**로 나눈다. 노션 페이지 경계를 따르지 않는다. 한 노션 페이지가 여러 개념에 걸치면 나누고, 여러 페이지가 한 개념이면 합친다.
4. 기존 페이지가 있으면 보강, 없으면 하위 개념을 만들어 새로 쓴다. 최상위 영역은 만들지 않는다.
5. `study_book` action=apply 한 묶음으로 적용한다: `create`, `write_page`, 그리고 쓴 페이지마다 사용한 원문을 `record_source`({kind:"notion", title, path:"sources/…md", url})로 남긴다.
6. 결과를 보고한다: 페이지별 새로 씀/보강함, 각 페이지에 쓴 원문 목록, 뺀 내용과 이유, `차이:` 링크, undo용 changeId.

## 재구성 원칙

- 교과서 구조: 핵심 한 문장 → 설명(그림·Mermaid 가능) → 예시(코드·표) → 주의할 점. 경로·하위 목록·관련 개념·배운 곳·참고한 자료는 자동 영역이 만든다.
- **밀도: 원문 내용의 60~70%를 살린다.** 원문의 설명 흐름·예시 코드·표·수치를 대부분 유지하고, 줄이는 것은 중복 설명, 장황한 서술, 개인 메모성 문장("~해보자", "TODO"), 같은 내용을 반복하는 캡처뿐이다. 요약해서 원문 링크로 넘기지 않는다.
- 원문의 그림이 설명에 꼭 필요하면 `sources/…/media/…` 상대 경로로 그대로 넣는다(`![설명](../../../sources/…/media/x.png)`). 장식용 캡처는 넣지 않는다.
- 원문에 근거가 없는 내용을 새로 지어내지 않는다.
- **원문이 틀렸거나 오래됐다고 판단되면 공식 문서로 확인한 뒤에만 고친다.** 확인한 곳은 본문을 바르게 쓰고 "주의할 점"에 원문 표현·바른 내용·근거 링크(공식 문서 URL)를 남긴다. 공식 문서로 확인하지 못하면 본문은 원문대로 두고 "주의할 점"에 "확인 필요"로만 적는다. 기억에 근거해 고치지 않는다.
- 외부 블로그·강의에서 가져온 문장과 그림은 출처 링크를 남긴다(원문에 있던 링크를 유지).
- 다른 개념은 한 줄 요약과 링크로만 언급하고, 영역이 다른 같은 주제는 `relate`로 잇는다.
- 원문이 비어 있으면 페이지를 만들지 않는다. 제목만 있는 원문은 해당 개념 페이지의 "주의할 점"이나 보고에 "원문 없음"으로 남긴다.
- 페이지 본문 하나는 60,000자 이하. 넘으면 하위 개념으로 나눈다.

## 하지 않는 것

- 원문을 통째로 복사하지 않는다(원문은 `sources/`에 있다).
- 명제(`study_knowledge`)를 만들지 않는다. 명제는 학습 챕터에서 확인된 지식만 다룬다.
- 사용자가 직접 고친 본문은 덮어쓰지 않는다. 거부되면 `adopt_page` 여부를 먼저 묻는다.
